# Support

CommerceLens is a beta project maintained through its GitHub repository.

## Questions and setup help

Read the [documentation index](docs/README.md) and search existing issues first. If the answer
is not documented, open a feature request or bug report and explain the outcome you are trying
to achieve.

## Bugs

Use the bug report form. Include a minimal reproduction, Python version, CommerceLens commit
or release, interface used, expected result, and actual result. Replace store URLs and product
data with safe examples. Never post credentials, customer pages, or production logs containing
sensitive data.

## Security vulnerabilities

Do not open a public issue. Follow [SECURITY.md](SECURITY.md) and use GitHub's private
vulnerability reporting flow.

## Commercial support

No response time or commercial support commitment is currently offered. A future support
policy should document supported releases, response targets, and any paid service terms before
they are advertised.
